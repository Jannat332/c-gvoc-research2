## 1. Benchmarks, Partitions, and Evaluated Models

We evaluate across four benchmark suites representing the core perceptual and layout challenges in visual document understanding:

| Dataset | Modality & Document Type | Primary Perceptual Bottleneck | Official Split Evaluated | Metric Evaluated |
| :--- | :--- | :--- | :--- | :--- |
| **DocVQA** \citep{mathew2021docvqa} | Scanned administrative documents, forms, receipts | Fine character strokes, small fonts, stamps | Validation Split | Average Normalized Levenshtein Similarity (ANLS) & Exact Match |
| **ChartQA** \citep{masry2022chartqa} | Bar charts, line graphs, pie charts | Baseline axis labels, legends, visual bar heights | Test Split | Relaxed Accuracy (5% numerical tolerance) |
| **TableBench** \citep{tablebench2024} | Financial statements, scientific tables | Multi-row alignments, merged cells, row headers | Public Benchmark Split | Cell Exact Match & Structural F1 |
| **MMLongBench-Doc** \citep{wang2024mmlongbenchdoc} | Multi-page academic reports, government filings | Cross-page navigation, peripheral footnotes | Standard Subset | Macro Accuracy |

## 2. Experimental Partitions

### A. Large-Scale Offline Diagnostic Simulation ($N = 16,000$ Queries)
- **Scale:** 4,000 queries per dataset across 4 foundation model profiles (Mistral Pixtral 12B, Qwen2-VL 27B, GPT-OSS 120B, Gemini 3.6 Flash; 64k sessions, 96k evaluated actions).
- **Counterfactual Branching:** 48,000 same-state transitions generated by evaluating candidate actions ($a_{\text{stop}}, a_{\text{reground}}, a_{\text{reexec}}, a_{\text{abstain}}$) from frozen intermediate states.
- **Role:** Evaluates the theoretical accuracy-compute Pareto frontier when candidate actions have access to ground-truth spatial coordinates.

### B. Live Empirical Pilot Benchmark ($N = 100$ Instances)
- **Model:** Mistral Pixtral-12B (`pixtral-12b-2409`) evaluated via official live API.
- **Sample:** 50 DocVQA instances and 50 ChartQA instances.
- **Conditions:** Monolithic Direct Inference vs. Original GVoC vs. Conservative C-GVoC on identical pre-registered instances (300 live API calls).
- **Role:** Empirical case study evaluating real-world foundation model deployment without idealized simulators.

### C. Prompt & Budget Diagnostic Probe ($N = 12$ Instances)
- **Sample:** 12 selected pilot instances (6 harmful flips, 3 beneficial, 3 stable).
- **Conditions:** 5 prompt/budget variants testing conversational prompts vs. format-constrained concise decoding under 60-token vs. 256-token budgets (60 live API calls).

### D. Factorial Image/Prompt Probe ($N = 20$ Instances, Exploratory)
- **Sample:** 10 DocVQA questions (spanning 5 document images) and 10 ChartQA questions (spanning 5 chart images).
- **Conditions:** Factorial combination of full native image, downsampled image, center 50% crop, conversational prompt, and concise prompt under 60-token limits (100 live API calls).
- **Classification:** Strictly labeled **Exploratory Pilot Probe** due to 100% overlap with the pilot dataset.

## 3. Evaluated Baselines & Control Policies

1. **Monolithic Zero-Shot VLM:** Single-turn inference on globally downscaled image $I_{\text{low}}$ using standard system instructions.
2. **Confidence-Based Router:** Evaluates candidate output softmax confidence $p_0$; triggers intervention if $p_0 < \tau_{\text{conf}}$ without action-value estimation.
3. **MACT (Multi-Agent Collaboration) \citep{yu2025visual}:** Four collaborative agents ($A_{\text{plan}}, A_{\text{exe}}, A_{\text{judg}}, A_{\text{ans}}$) with up to 3 iterative self-correction loops on static image $I_{\text{low}}$.
4. **Deterministic Always-Intervene Rule:** Forcibly triggers visual intervention ($a_{\text{reground}}$ on documents; $a_{\text{reexec}}$ on tables) on $>85\%$ of queries.
5. **GVoC (Point-Estimate, Ours):** Evaluates unregularized intervention value $\mathcal{V}(s, a) = \hat{\Delta P}_a / C(a)$.
6. **C-GVoC (Conservative LCB, Ours):** Evaluates dispersion-penalized value $\mathcal{V}_{\text{LCB}}(s, a) = (\hat{\Delta P}_a - \kappa \hat{\sigma}_a) / C(a)$.
7. **Evaluated-Action Oracle ($\mathcal{A}^*$):** Perfect hindsight selector choosing the optimal action for each query with minimum token cost.

## 4. Controlled Variables & Fairness Protocol

- **Prompts:** Standardized across all conditions except when isolating prompt verbosity in the diagnostic probe.
- **Decoding Settings:** Greedy decoding (temperature $T = 0.0$, top-$p = 1.0$) across all live model API calls to ensure deterministic reproducibility.
- **Cost Accounting:** All completion tokens, prompt tokens, and intervention tool calls are measured and logged per query.
