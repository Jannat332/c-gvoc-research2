## 1. Executive Summary

This inventory audits all evaluation paths, model provider configurations, datasets, and codebase components in `ESWA_ehte` to establish an honest, unvarnished baseline before running live empirical validation.

**Key Findings:**
1. **Zero Prior Live Inferences on Benchmark:** None of the 96,000 evaluations reported in `gvoc_engine/experiments/run_full_16k_benchmark.py` or stored in `gvoc_evaluation.db` (`benchmark_evaluations`) were live model calls. All were generated by deterministic heuristic functions (`evaluate_monolithic`, `evaluate_fixed_veccap`, etc.) operating on synthetically sampled failure labels.
2. **Hidden Mock Fallbacks:** `UnifiedClientManager` (`gvoc_engine/providers/client_manager.py`) contains silent fallback traps at lines 69, 94, and 123 that return hardcoded `MockClient` outputs on any API exception, rate limit, timeout, or missing package, with zero indication in the return signature that a mock was invoked.
3. **Decommissioned / Invalid Model Identifiers:** Three out of five model configurations in `gvoc_engine/config.py` are non-functional (`llama-3.2-11b-vision-preview` was decommissioned by Groq; `gemini-2.5-flash` / `gemini-3.6-flash` are not accepted on Google's v1beta endpoint; `qwen/qwen-2-vl-7b-instruct:free` has no active endpoints on OpenRouter).
4. **Verified Live Multimodal Models:** Two genuine, high-throughput VLM endpoints have been empirically verified with multimodal image inputs:
   - **Mistral Pixtral-12B** (`pixtral-12b-2409`) via Mistral API (latency ~0.85s, verified OCR extraction).
   - **Qwen2.5-VL-72B** (`qwen/qwen2.5-vl-72b-instruct`) via OpenRouter API (latency ~1.29s, verified OCR extraction).
5. **Synthetic Benchmark Datasets:** The 4,000 JSON lines in `gvoc_engine/data/*.jsonl` contain no document images; they were procedurally generated text templates from `dataset_generator_16k.py`. Genuine document-question-image instances from official DocVQA (`nielsr/docvqa_1200_examples`) and ChartQA (`HuggingFaceM4/ChartQA`) are available via official public endpoints.

## 4. Dataset & Ground-Truth Availability

### Historical Repository Data (`gvoc_engine/data/*.jsonl`)
- **Status:** Synthetically generated text records created by `gvoc_engine/benchmark/dataset_generator_16k.py`.
- **Limitation:** Contains no image files, no bounding boxes of real images, and templated text queries (e.g., `DOC-4265`).
- **Research Validity:** Cannot be used for genuine visual document understanding evaluation because no visual document is processed.

### Genuine Public VDU Benchmarks Available
1. **DocVQA (Document Visual Question Answering)**
   - **Split:** Test / Validation (`nielsr/docvqa_1200_examples`).
   - **Contents:** High-resolution scans of real industry, administrative, and legal documents.
   - **Annotations:** Multi-annotator ground truth strings, bounding boxes, word transcriptions.
   - **License:** Open Academic Use (CC BY-NC 4.0 / UCSF Industry Documents).
2. **ChartQA (Visual Chart Reasoning)**
   - **Split:** Test split (`HuggingFaceM4/ChartQA`).
   - **Contents:** Real chart images (bar, line, pie, scatter) covering financial and scientific charts.
   - **Annotations:** Exact numerical and categorical answers with human vs. machine question splits.
   - **License:** Open Research Use (CC BY-SA 4.0).
