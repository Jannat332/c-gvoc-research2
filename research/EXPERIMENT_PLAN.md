## 1. Benchmark Suites & Dataset Provenance

We evaluate across four standard public benchmarks spanning diverse visual document reasoning challenges:

| Benchmark | Domain / Visual Structure | Primary Bottleneck | Metric | Official Source & Split |
| :--- | :--- | :--- | :--- | :--- |
| **DocVQA** \citep{mathew2021docvqa} | Scanned invoices, letters, forms | Tiny text characters, degraded resolution | Average Normalized Levenshtein Similarity (ANLS) / Exact Match | Validation split (5,349 images, 50,186 questions) |
| **ChartQA** \citep{masry2022chartqa} | Bar charts, line plots, pie graphs | Axis labels, legends, visual data extraction | Relaxed Accuracy (5% tolerance on numerical values) | Test split (1,250 human + 1,250 machine generated) |
| **TableBench** \citep{tablebench2024} | Financial tables, scientific tabular grids | Row/column misalignment, multi-cell calculation | Cell Exact Match & Structural F1 | Public benchmark split |
| **MMLongBench-Doc** \citep{wang2024mmlongbenchdoc} | Multi-page manuals, academic reports | Cross-page navigation, peripheral footnotes | Macro Accuracy | Standard evaluation subset |

## 2. Experimental Partitions & Datasets

### A. Large-Scale Benchmark Simulation ($N = 16,000$ Queries)
- **Architecture:** 4,000 queries per dataset across 4 VLM backbones (Mistral Pixtral 12B, Qwen2-VL 27B, GPT-OSS 120B, Gemini 3.6 Flash) spanning 64,000 sessions and 384,000 state transitions.
- **Counterfactual Branching:** $N = 48,000$ transitions generated by executing candidate actions ($a_{\text{stop}}, a_{\text{reground}}, a_{\text{reexec}}, a_{\text{abstain}}$) from frozen intermediate states $s$.
- **Offline Role:** Used to fit the dual-head LightGBM advantage estimator and benchmark the theoretical ceiling of cost-aware observation scaling.

### B. Live Empirical Pilot Benchmark ($N = 100$ Instances)
- **Backbone:** Mistral Pixtral-12B (`pixtral-12b-2409`) accessed via live official API.
- **Protocol:** Monolithic Direct Inference vs. Original GVoC vs. Conservative C-GVoC on identical pre-registered instances (50 DocVQA, 50 ChartQA).
- **Total API Calls:** 300 calls (100 instances $\times$ 3 conditions).

### C. Prompt & Budget Diagnostic Probe ($N = 12$ Instances)
- **Scope:** 5 prompt/budget conditions on 12 selected pilot instances (6 harmful, 3 beneficial, 3 stable) to isolate conversational preambles vs. format-constrained concise decoding.
- **Total API Calls:** 60 live calls.

### D. Exploratory Factorial Probe ($N = 20$ Instances)
- **Scope:** Factorial evaluation across 5 conditions (C1: Full Concise 60t; C2: Downsampled Concise 60t; C3: Downsampled Verbose 256t; C4: Center 50% Crop Concise 60t; C5: Full Verbose 60t).
- **Status:** Strictly labeled **exploratory pilot probe** due to overlap with the pilot set.
- **Total API Calls:** 100 live calls.

## 3. Evaluated Baselines & Control Policies

1. **Monolithic Zero-Shot VLM:** Standard single-turn feed-forward inference on downsampled image $I_{\text{low}}$.
2. **Confidence-Based Router:** Intervenes whenever softmax candidate confidence $p_0 < \tau_{\text{conf}}$ without action-value estimation.
3. **MACT (Multi-Agent Collaboration) \citep{yu2025visual}:** Procedural reasoning framework using 4 collaborative agents ($A_{\text{plan}}, A_{\text{exe}}, A_{\text{judg}}, A_{\text{ans}}$) with up to 3 self-correction loops on static image $I_{\text{low}}$.
4. **Deterministic Always-Intervene Rule:** Forcibly triggers visual intervention ($a_{\text{reground}}$ on documents; $a_{\text{reexec}}$ on tables) on $>85\%$ of queries.
5. **GVoC (Point-Estimate, Ours):** Evaluates unregularized intervention value $\mathcal{V}(s, a) = \hat{\Delta P}_a / C(a)$.
6. **C-GVoC (Conservative LCB, Ours):** Evaluates dispersion-penalized value $\mathcal{V}(s, a) = (\hat{\Delta P}_a - \lambda \hat{\sigma}_a) / C(a)$.
7. **Evaluated-Action Oracle ($\mathcal{A}^*$):** Perfect hindsight selector choosing the optimal action for each query with minimum cost.

## 4. Evaluation Metrics

1. **Task Accuracy (%):** Benchmark-specific correctness (Exact Match for DocVQA; 5% numerical tolerance for ChartQA; Cell F1 for TableBench).
2. **Average Tokens per Query:** Total tokens generated across all inference steps (including planning, reasoning, and tool calls).
3. **Empirical Oracle Regret $\mathcal{R}(\pi)$:**
   $$\mathcal{R}(\pi) = \frac{1}{N} \sum_{i=1}^N \left[ \text{Loss}(i, \pi(s_i)) - \min_{a \in \mathcal{A}} \text{Loss}(i, a) \right]$$
   where $\text{Loss}(i, a) = 0.85 \cdot \mathbb{I}[Y_i(a)=0] + 0.15 \cdot \frac{C_i(a)}{C_{\max}}$.
