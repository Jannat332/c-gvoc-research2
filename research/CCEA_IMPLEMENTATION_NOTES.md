# Context-preserving evidence acquisition: implementation notes

## Purpose
This patch adds a deterministic pre-flight check for proposed visual crops. It is **not** a trained semantic detector or proof of improved VDU accuracy. Required context boxes must be annotated or generated by a grounded layout locator.

## API
- `EvidenceRegion`: target box plus required semantic context regions.
- `assess_crop(...)`: rejects crops that omit most of the target or any declared header, row/column label, unit, legend, axis tick, footnote, or neighboring cell.
- `propose_context_preserving_crop(...)`: covers the target and supplied context boxes, then adds a margin.
- `expand_box(...)`: expands a crop while clipping to image boundaries.

Coordinates are integer pixel boxes `[ymin, xmin, ymax, xmax]`, with exclusive maximum bounds.

## Integration sequence
1. Run normal overview inference.
2. Obtain/annotate the target region and required context.
3. Propose a higher-resolution crop covering both.
4. Assess the crop before making another VLM call.
5. If invalid, rebuild/expand it. If no valid crop fits the remaining budget, stop or abstain according to evidence adequacy.
6. Evaluate the produced answer against ground truth. Do not treat fixed changes to internal confidence scores as observed accuracy.

## Current methodological limitation
The current `execute_reground` obtains a model response but does not parse/validate the returned box, and modifies `d_layout`, `d_evidence`, and `c_judg` with fixed multipliers regardless of response validity. The main router also relies on hand-written gain and uncertainty heuristics. This patch only makes geometric retention of explicitly supplied context testable; it does not solve model calibration.

## Validation
Run `python -m unittest gvoc_engine.tests.test_context_preservation`.

These tests validate geometry/fail-closed behavior only. Empirical claims require a held-out ablation comparing the same acquisition/controller with and without the context-retention constraint.
